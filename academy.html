Overview

This study guide brings together the core themes, tools, and skills taught across the Mr. Paul ICT Academy curriculum, drawing on real classroom materials, project work, and hands-on assignments. Rather than a generic list of software names, it is built to show how each subject area connects to practical, employable ICT competence — from everyday office productivity to full-stack web and database development.

It is intended for learners revising for assessments, for parents and partners who want a clear picture of what the academy delivers, and for the wider public looking to understand the standard of instruction on offer. Each topic below reflects skills that are directly transferable to the workplace, further study, or independent freelance work.

Main Topics / Themes

Core ICT Teaching Materials. Learners build fluency across the Microsoft Office suite — Word, Excel, PowerPoint, and Access — progressing from basic document handling to advanced, exam-ready and workplace-ready proficiency.

Web Development Projects. Students design and build real websites, including personal portfolios, animated interfaces, and fully responsive layouts that adapt cleanly across desktop and mobile devices.

School Management Systems. A flagship project stream centres on building a working report card / school management system using PHP, MySQL, and XAMPP — giving learners genuine backend development and database experience, not just theory.

AI & Automation. The academy introduces learners to building and deploying a personal AI assistant, including how such tools can be integrated into branding and social media workflows for individuals and small businesses.

Graphic Design & Brand Identity. Learners also explore logo design and visual identity development, using the Mr. Paul ICT Academy brand itself as a live case study in professional design practice.

Important Details

Word & PowerPoint. Document formatting, page layout design, and presentation delivery skills, aimed at producing polished, professional-grade output.

Excel. Beyond formulas and charts, learners cover VBA automation, Mail Merge workflows, and structured data analysis techniques used in real office environments.

Access. Database design fundamentals, including table structure, query building, and report generation for organised data management.

Web Design. Practical CSS skills — animations, hover effects, and responsive media queries — that let learners build sites which look and behave well on any screen size.

PHP & MySQL. The backend logic powering the academy's school report card system, giving learners a concrete example of how a real, functioning application is built end to end.

AI Assistant Development. Practical guidance on integrating AI tools with social media presence and brand identity, reflecting current, in-demand digital skills.
